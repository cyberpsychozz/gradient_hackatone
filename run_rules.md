Формат решения и правила заезда

Команда отправляет ZIP с программой обучения. Сервер собирает образ, запускает train.py на видеокарте и получает файл /output/policy.onnx. В закрытом испытании исполняется только этот файл: исходники Python и Dockerfile больше не запускаются. Вы можете менять алгоритм обучения и устройство сети, если итоговая модель соблюдает описанный ниже формат.
ZIP и вычислительная среда

В корне архива нужны Dockerfile, train.py и README.md. Остальные файлы, включая исходники C++, модули Python и тренировочные трассы, размещайте рядом. Размер ZIP не более 32 МиБ, распакованных файлов — до 128 МиБ и 512 штук. Символические ссылки, вложенный ZIP вместо исходников и готовые файлы весов не принимаются. Сборка принимает только один этап FROM arena-base; реальный базовый образ сервер подставляет сам.

Сборка 	4 ядра 	8 ГиБ 	нет 	до 40 минут 	HTTPS для установки библиотек

Начальный образ содержит Python 3.12, PyTorch 2.14 с CUDA, NumPy, Gymnasium, PyYAML, ONNX, pybind11, компилятор C++ и среду марсохода 0.16.0. Свои зависимости с точными версиями добавляйте в Dockerfile. Обучение запускается от отдельного непривилегированного пользователя. Временные файлы храните в /tmp, итоговый файл — в /output/policy.onnx.
Модель ONNX

Версия формата — rover-policy-onnx-v1, версия ONNX opset — 17. В метаданных модели нужна запись rover.format=rover-policy-onnx-v1. Поля producer_name, doc_string и ключи format или format_version её не заменяют. Функции экспорта ниже добавляют нужную запись автоматически. Первая размерность каждого входа и выхода должна называться batch: на проверке одновременно идут 48 заездов. Модель может быть полносвязной, рекуррентной, свёрточной или сочетать разные блоки. Все семь входов должны присутствовать в графе, даже если сеть использует лишь часть из них.
Вход 	Тип и размер 	Значение
observation 	float32 [batch, 160] 	Показания датчиков и состояние марсохода
previous_action 	int64 [batch] 	Номер предыдущей команды: 0–30
previous_reward 	float32 [batch] 	Сумма наград среды за предыдущее действие
previous_done 	float32 [batch] 	Признак завершения предыдущего шага; в текущих независимых заездах обычно 0
trial_progress 	float32 [batch] 	Доля времени текущего заезда: 0–1
trial_start 	float32 [batch] 	1 на первом действии нового заезда
memory 	float32 [batch, M] 	Память сети; 1 ≤ M ≤ 4096

Начальная память заполнена нулями. После каждого действия сервер передаёт next_memory обратно в memory. Перед новым заездом память очищается. Для сети без памяти используйте M=1 и возвращайте ноль.
Выход 	Тип и размер 	Значение
logits 	float32 [batch, 31] 	Оценка каждой команды
next_memory 	float32 [batch, M] 	Память для следующего действия

Выбирается индекс наибольшего значения logits; вычислять вероятности не нужно. Выходы должны быть конечными, по модулю не больше 1 000 000. Файл должен быть одним обычным файлом размером до 32 МиБ без внешних данных. Запрещены пользовательские операторы, управляющие подграфы, генераторы случайности и вычисления, способные бесконтрольно увеличивать память. Ошибки формата модель получит на этапе проверки, до запуска ONNX Runtime.

Начальное решение сохраняет Policy так:

from arena.protocol import export_agent_onnx
export_agent_onnx("/output/policy.onnx", model, rms)

Для другой программной структуры подготовьте torch.nn.Module.forward с семью аргументами из таблицы и двумя возвращаемыми массивами, затем вызовите:

from arena.protocol import export_onnx
export_onnx("/output/policy.onnx", module, obs_dim=160, memory_size=M)

Обе функции сохраняют входы, которые ваша сеть не использует, и проверяют результат перед завершением обучения. Сохраните модель хотя бы один раз до истечения двух часов; лучше обновлять файл после каждого успешного этапа.
Ограничения графа и проверка экспорта

В итоговом графе допускается от 1 до 1024 операций. Это число узлов ONNX, а не число слоёв PyTorch: один слой может превратиться во множество операций. Полный список разрешённых операций:

Abs Add And ArgMax BatchNormalization Cast Ceil Clip Concat Constant Conv Div
Elu Equal Erf Exp Flatten Floor Gather GatherElements GatherND Gemm
GlobalAveragePool Greater GreaterOrEqual GRU HardSigmoid Identity
LayerNormalization LeakyRelu Less LessOrEqual LSTM MatMul Max MaxPool Mean Min
Mod Mul Neg Not OneHot Pad Pow Reciprocal ReduceMax ReduceMean ReduceMin
ReduceSum Relu Reshape Shape Sigmoid Sign Slice Softmax Split Sqrt Squeeze Sub
Tanh Transpose Unsqueeze Where

Другие операции, в том числе ConstantOfShape, Or, Log и Cos, текущий оценщик не принимает. Наличие операции в ONNX opset 17 само по себе не означает, что она поддерживается на площадке. При экспорте PyTorch может добавить такие операции, даже если вы не вызывали их явно.

После определения размеров массивов сервер также проверяет расход памяти: до 8 000 000 элементов в одном массиве и до 64 000 000 элементов суммарно в промежуточных массивах графа. Для Pad и OneHot действуют дополнительные проверки размеров. Проверку выполняет arena.protocol из базового образа; параметры безопасности нельзя обойти, заменив модуль в своём ZIP.

До длительного обучения вызовите функцию экспорта для вашей сети с начальными весами. Если она выдаёт ошибку, исправьте экспорт прежде, чем обучать модель. Для проверки уже сохранённого файла в контейнере с базовой средой выполните:

python /submission/check_policy.py /output/policy.onnx

check_policy.py входит в начальный архив. Он проверяет формат и ограничения графа, а при наличии ONNX Runtime — ещё и выполнение модели. Обычный torch.onnx.export не добавляет метаданные площадки и не заменяет эту проверку. Не подавляйте ошибку экспорта с последующим завершением программы с кодом 0: без корректного /output/policy.onnx серверу нечего оценивать.

Как считается результат

Оценщик запускает 48 независимых заездов по 300 секунд модельного времени: девять отдельных типов трассы и семь последовательностей участков, каждый с тремя вариантами мира. Марсоход проходит один заезд до поломки или истечения времени; после поломки этот заезд заканчивается. В каждом заезде учитывается наибольшее достигнутое расстояние от старта за вычетом первого метра. Откат назад его не уменьшает. Балл — медиана 48 расстояний в метрах. Верхнего ограничения балла нет. В закрытой проверке сложность трассы максимальна с самого начала; для испытаний используется неизменный набор миров организаторов.

Исходники среды и порядок тренировочных участков, вложенные в ваш ZIP, влияют на обучение. Проверка запускает собственную сборку среды с тем же форматом наблюдений, команд и конструкцией марсохода. На закрытых трассах встречаются незнакомые участки и эффекты; отдельные траектории не обязаны совпадать с тренировочными даже при одинаковом начальном числе генератора случайных чисел. Если поменять число наблюдений, таблицу команд или конструкцию марсохода в тренировочной сборке, полученная модель не пройдёт проверку либо будет вести себя иначе.

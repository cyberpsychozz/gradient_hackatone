## Замечания
- **Локальная сборка**: callbacks биомов активны только для ID 20-39 (`docs/worlds.md`),
  поэтому медианы биомов 0-19 занижены относительно закрытого заезда; сравнивать алгоритмы
  корректнее по биомам 20-39 и по цепочке.
- DQN и REINFORCE на 6-минутном CPU-тренинге не дали едущей жадной политики (медиана ~0 м):
  DQN не доснизировал epsilon (0.77), REINFORCE ушёл в расходящуюся потерю (MC-возвраты,
  высокая дисперсия). Нужны длинный тренинг и/или настройка гиперпараметров.
- A2C и CEM обучаются стабильно и едут: медиана по биомам ~650 м и ~590 м, цепочка ~310 м.
- Это sanity-check на CPU, не финальная оценка; полный тренинг 2 ч на GPU изменит картину.

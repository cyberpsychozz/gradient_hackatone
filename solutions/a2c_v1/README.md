# A2C v1 — Advantage Actor-Critic (синхронный)

Классический **A2C** для Mars Rover: общий энкодер + головки актёра (31 команда) и критика
(одно значение). n-step возвраты с бустрепом от критика, преимущество — как разность
`return − V`, без GAE и без clip/importance ratio (в отличие от PPO). Модель без памяти (`M=1`).

## Особенности

- Контекст решения: observation[160] + one-hot предыдущей команды + награда/флаг/доля времени.
- Одно RL-решение = 8 шагов физики (`frame_skip=8`), rollout 64 шага, батч по 16 сред.
- `gamma=0.99`, `value_coef=0.5`, `entropy_coef=0.01`, lr 3e-4.
- В выход `logits` идут логиты политики; аргмакс на сервере выбирает команду.

## Запуск

```bash
python train.py                                   # полное обучение
python train.py --total-frames 100000 --num-envs 8 \
  --rollout-steps 16 --epochs 1                   # короткий прогон
python check_policy.py artifacts/policy.onnx
```

## Пределы

- Без рекуррентной памяти сеть не видит дальний рельеф и фазы биомов; для сравнения
  с PPO/A2C это нормальный «базовый» ориентир.

# REINFORCE v1 — классический policy gradient с baseline

Базовый **REINFORCE** для Mars Rover: полные заезды (trial) собираются в эпизоды,
дисконтированные Monte-Carlo-возвраты `G_t = Σ γ^k r_{t+k}`, критика обучается как baseline
регрессией на эти возвраты. Обновление политики — `∇ log π(a|s) · (G − V(s))` с per-эпизодной
нормализацией преимущества. Модель без памяти (`M=1`).

## Особенности

- Заезд длится 300 с (18000 шагов физики), одно RL-решение = 8 шагов (`frame_skip=8`).
- Обновление происходит, когда накопится `--update-every` (по умолчанию 32768) решений;
  градиенты усредняются по всем завершённым эпизодам.
- `gamma=0.99`, `value_coef=0.5`, `entropy_coef=0.01`, lr 3e-4.
- Выход `logits` — логиты политики.

## Запуск

```bash
python train.py                                     # полное обучение
python train.py --total-frames 100000 --num-envs 8 \
  --update-every 4096                               # короткий прогон
python check_policy.py artifacts/policy.onnx
```

## Пределы

- Monte-Carlo-оценка по полным эпизодам даёт высокую дисперсию; это сознательно самый
  «честный» базовый градиентный метод для сравнения с A2C/PPO.

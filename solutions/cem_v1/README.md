# CEM v1 — Cross-Entropy Method (эволюция линейной политики)

Black-box оптимизация параметров линейной политики (`logits = x·W + b`) методом
**Cross-Entropy**: на каждой генерации выборка кандидатов из нормального распределения,
оценка дистанции каждого кандидата в параллельных окружениях, элитный топ (20%)
пересобирает гауссово распределение. Никаких градиентов и нейросетей — самый простой
базовый ориентир.

## Особенности

- Популяция = `--pop-size` сред, каждая среда едет политикой своего кандидата
  `--eval-steps` решений (одно решение = 8 шагов физики).
- Модель без памяти (`M=1`), на сервере выбирается argmax logits.
- Параметров: 194×31 + 31 = 6045 (obs + one-hot команды + награда/флаг/доля времени).

## Запуск

```bash
python train.py                                   # полное обучение
python train.py --pop-size 8 --generations 2 \
  --eval-steps 60                                 # короткий прогон
python check_policy.py artifacts/policy.onnx
```

## Пределы

- Линейная политика не может решать сложные биомы (фазы, леджи), но быстро показывает
  нижнюю границу результата для сравнения с градиентными методами.
